# 隐私与本地数据

Glint 不包含分析统计、遥测或自动更新服务。原生引擎监听选词相关的系统事件以触发浮条；选中文字会暂存在当前进程内存中，不会因选中动作自动写入记录数据库。

## 网络

- 点击 AI 动作（包括「测试浮条」中的 AI 动作）后，原文和提示词会发送到用户配置的模型 API；重试会再次发送。
- 点击 Google 搜索会通过默认浏览器发送查询文字（最多前 4,000 字符），适用搜索服务自己的隐私政策。
- 复制动作不调用模型。图标离线加载。
- 安装依赖时，npm 和 Electron 安装器需要联网下载；这与应用运行时的数据流不同。

## 存储

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\Glint\settings.json` | 动作、模型地址、模型名称等配置，及 Windows safeStorage 加密的 API Key |
| `%APPDATA%\Glint\` 其他文件 | Electron 的配置、缓存和运行时资料 |
| `%LOCALAPPDATA%\Glint\data\translations.sqlite` | 手动记录的翻译原文、结果、来源进程和时间 |
| `%LOCALAPPDATA%\Glint\data\polishing.sqlite` | 手动记录的润色原文、结果、来源进程和时间 |
| `%LOCALAPPDATA%\Glint\logs\glint.log` | 生命周期、请求状态、耗时、错误码和数据库操作状态 |

数据库为未加密 SQLite，不保存 API Key；只有内置翻译和润色动作提供记录按钮。生成中或结果为空时不能记录；停止后的部分结果可手动保存。同一卡片重试后再次记录会更新结果，并保留首次记录时间。

日志不写原文、模型回复或密钥；`glint.log` 约 1 MiB 轮换，保留 3 个备份。排查问题时仍需检查并脱敏你准备公开的截图和诊断信息。

旧版 `work/` 数据库可能在首次升级时迁移到 AppData，原文件保留为备份；既有记录缺少的结果、进程字段保留为空。测试使用 `work/smoke-profile/` 独立配置、日志与数据库。

## 删除与备份

先从托盘或设置退出 Glint，再备份或删除上述对应文件。要彻底清除应用数据，可删除 `%APPDATA%\Glint` 和 `%LOCALAPPDATA%\Glint`，以及可能保留的旧 `work/` 数据库、测试目录和自行创建的备份；下次启动会建立空数据文件。删除仅是普通文件删除，不承诺安全擦除。数据目录和加密后的凭据同样不应上传 GitHub。
