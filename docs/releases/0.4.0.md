# Glint 0.4.0 · Preview / 预览版

更方便地整理历史记录，更舒适地编辑长提示词、阅读长回答。

Manage saved records more easily, with more room for long prompts and answers.

## 本次更新 / What's new

- **历史记录更易管理**：支持删除单条记录；右侧原文和结果分别滚动，顶部集中提供复制原文、复制结果和删除按钮。/ Delete individual records, scroll the original and result independently, and access both copy actions and deletion from the detail header.
- **设置空间更充分**：动作、触发和诊断页充分利用窗口高度；提示词输入框随可用空间展开，长内容可在框内滚动。新建动作移到动作列表，测试浮条移到预览区。/ Actions, Triggers and Diagnostics use the available window height. The prompt editor expands with the panel and scrolls internally. Create actions from the action list and test the toolbar beside its preview.
- **结果卡片更舒适**：调整按钮尺寸和间距，简化原文展开按钮样式，恢复轻巧的圆点加载动画。/ More comfortable button sizes and spacing, a simpler source-text toggle, and a compact animated-dot loading indicator.
- **维护与验证**：拆分界面组件、统一设置状态和通信类型；完整测试与正式包分离，并修正原生取词测试的鼠标目标定位。此项修正针对测试，没有改变第三方应用的取词兼容性。/ Separate UI components, centralize settings state and IPC types, and keep full test scenarios out of production packages. Native tests now control the pointer target; this test fix does not change third-party selection compatibility.

## 更新与数据 / Updating and data

更新前请从托盘菜单完全退出 Glint，再运行新版安装程序或替换 portable exe。关闭设置窗口仅会隐藏窗口。已有设置、动作和记录继续保留；删除历史记录会从对应动作的数据库移除该条记录。

Quit Glint from the tray menu before installing the update or replacing the portable exe. Closing settings only hides the window. Existing settings, actions and records are preserved; deleting a history entry removes that entry from its action database.

记录保存在 `%LOCALAPPDATA%\Glint\data`，设置保存在 `%APPDATA%\Glint`。记录仅在点击「记录」后保存，数据库未加密。Portable 和安装版共用 AppData，数据不会随 exe 一起移动。

Records live in `%LOCALAPPDATA%\Glint\data`, and settings in `%APPDATA%\Glint`. Records are saved only when you click Save and use unencrypted databases. Portable and installed editions share AppData; data does not travel with the executable.

当前为未签名预览版，Windows 可能提示未知发布者。暂不支持自动更新、历史搜索、OCR 或 ARM64。快捷键取词时请将鼠标留在选中文字的窗口内；取词支持因应用而异。

This is an unsigned preview; Windows may show an unknown publisher warning. Automatic updates, history search, OCR and ARM64 are not supported yet. Keep the pointer in the window containing the selection when using the capture shortcut; support varies across applications.
