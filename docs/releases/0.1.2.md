# Glint 0.1.2 · Preview / 预览版

选中文字，即刻翻译、润色、搜索或复制。支持自定义动作与离线图标、紧凑浮条、流式结果，以及翻译/润色的本地记录。

Select text to translate, polish, search or copy. Customize actions and icons, stream results in a compact card, and optionally save translations and polished text locally.

## 下载 / Downloads

- **portable.exe**：免安装，双击运行 / Run without installing.
- **setup.exe**：安装向导、开始菜单入口和卸载 / Installer, Start menu shortcut and uninstaller.
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验 / SHA-256 checksums.

Windows 10/11 **x64**。无需 Node.js 或其他开发工具 / No developer tools required.

## 使用说明 / Notes

- 两个版本的数据均位于当前用户的 AppData，portable 不携带设置和记录。/ Both editions store data in the current user's AppData; portable does not carry settings or records with the exe.
- 在「模型」中配置自己的 OpenAI 兼容 API，复制与搜索无需模型。/ Configure your own OpenAI-compatible API; copy and search do not need a model.
- 当前界面为中文，README 提供中英切换。/ The app UI is Chinese; the README is available in Chinese and English.
- 尚未签名，Windows 可能显示未知发布者。暂不支持自动更新、OCR 和 ARM64。/ Unsigned preview; Windows may show an unknown publisher warning. No automatic updates, OCR or ARM64 support yet.
- 不保证所有应用都能取词；原生 UIA 自动化测试存在间歇性读取失败的已知情况。/ Selection support varies by app; intermittent native UIA capture failures have been observed in desktop tests.

更新前请完全退出 Glint；设置与记录会保留。/ Quit Glint completely before updating; settings and records are retained.
