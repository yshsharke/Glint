# Glint 0.3.0 · Preview / 预览版

将值得保留的回答存下来，按动作回顾原文和结果。

Save useful answers and revisit the original text and result for each action.

## 本次更新 / What's new

- **历史记录**：新增「历史」页，按动作切换分类，分页浏览原文、结果、来源进程和时间，支持分别复制与刷新。/ A new History page groups records by action, with pagination, source process and time, refresh, and separate copy buttons for the original and result.
- **所有指令均可记录**：翻译、解释、润色及自定义指令各自使用独立 SQLite 数据库。停用动作后仍可查看历史；重试后再次记录会更新同一条结果。/ Translate, Explain, Polish and custom instructions each use their own SQLite database. Disabled actions remain in History, and saving after a retry updates the same record.
- **清晰的动作命名**：新建动作时填写显示名称和唯一英文名称；英文名称首次保存后固定并隐藏，显示名称和图标仍可修改，历史标签同步更新。/ New actions require a display name and a unique English name. The English name identifies the database and is hidden after the first save; display names and icons remain editable and update History tabs.
- **更简洁的动作类型**：统一为「指令」「搜索」，移除浮条复制动作；结果卡片和历史页仍可复制文字。/ Action types are now Instruction and Search. The toolbar Copy action is removed; result cards and History retain their copy buttons.
- **兼容已有数据**：自动补齐旧动作的英文名称，保留原有翻译和润色数据库、设置及凭据。/ Existing actions receive English identifiers automatically, while translation and polishing databases, settings and credentials are preserved.

## 更新与数据 / Updating and data

更新前请从托盘菜单完全退出 Glint，再运行新版安装程序或替换 portable exe。关闭设置窗口仅会隐藏窗口，不会退出后台进程。

Quit Glint from the tray menu before installing the update or replacing the portable exe. Closing settings only hides the window; it does not stop the background process.

记录保存在 `%LOCALAPPDATA%\Glint\data`，设置与动作名称对应关系保存在 `%APPDATA%\Glint\settings.json`。所有记录均由用户点击「记录」后保存，数据库未加密。删除动作不会删除其数据库。Portable 和安装版共用 AppData，数据不会随 exe 一起移动。

Records live in `%LOCALAPPDATA%\Glint\data`; settings and action names live in `%APPDATA%\Glint\settings.json`. Records are saved only when you click Save and use unencrypted databases. Deleting an action leaves its database intact. Portable and installed editions share AppData; data does not travel with the executable.

当前为未签名预览版，Windows 可能提示未知发布者。暂不支持历史搜索、自动更新、OCR 或 ARM64；第三方应用的取词兼容性各不相同。

This is an unsigned preview; Windows may show an unknown publisher warning. History search, automatic updates, OCR and ARM64 are not supported yet. Text selection support varies across applications.
