# Glint 0.2.0 · Preview / 预览版

更紧凑、更统一的 Windows 划词体验。选中文字即可翻译、润色、解释、搜索或复制，让常用操作留在手边。

A more polished, compact text selection assistant for Windows. Select text to translate, polish, explain, search or copy without breaking your flow.

## 本次更新 / What's new

- **统一的界面与动效**：设置页、划词浮条和结果卡片采用官方 Fluent UI React v9，支持浅色、深色主题及系统减少动态效果设置。/ Settings, the selection toolbar and result cards now use official Fluent UI React v9, with light/dark themes and respect for reduced-motion preferences.
- **更方便的动作编辑**：名称、图标和类型在同一行；图标同时显示图形与名称，提示词和浮条预览集中展示。/ Edit an action's name, icon and type in one row, with labeled icons, prompts and a toolbar preview on the same page.
- **更细致的交互**：统一导航和动作列表的中性色反馈，优化间距与控件对齐，修正关闭按钮图标的悬浮颜色。/ Refined spacing, alignment and neutral navigation/action highlights, plus corrected close-button hover colors.
- **更直观的外观设置**：以按钮直接选择浮条密度，与主题和强调色选择保持一致。/ Choose toolbar density directly with buttons, alongside theme and accent options.
- **更稳定的编辑体验**：状态更新时保留输入焦点和未保存内容，修正弹层遮挡，改善键盘操作与弹窗焦点恢复。/ Preserve focus and unsaved edits during status updates, with improved overlays, keyboard navigation and dialog focus restoration.
- **更清晰的诊断页**：最近事件在固定区域内滚动，运行状态和提示保持可见。/ Recent events scroll within their own area while status and guidance remain visible.
- **更直接的托盘操作**：左键单击打开设置；右键菜单提供打开设置、停止或启用划词、退出。/ Left-click the tray icon to open settings; right-click to open settings, disable/enable selection or quit.
- 设置页显示完整版本号；中英文 README 更新了浮条、翻译弹窗和动作设置截图。/ Settings show the full app version, and both READMEs include updated toolbar, translation and Actions screenshots.

## 更新与使用 / Updating and usage

更新前请从托盘菜单完全退出 Glint，再运行新版安装程序或替换 portable exe。两个版本共享当前 Windows 用户的 AppData 数据，已有设置和记录会保留；portable 不携带这些数据随 exe 移动。

Quit Glint from the tray menu before installing the update or replacing the portable exe. Both editions share the current Windows user's AppData; existing settings and records are retained. Portable data does not travel with the executable.

在「模型」中配置自己的 OpenAI 兼容 API；复制和搜索无需模型。当前界面为中文，README 支持中英切换。

Configure your own OpenAI-compatible API under Model. Copy and search do not require a model. The app UI is Chinese; the README is available in Chinese and English.

当前为未签名预览版，Windows 可能提示未知发布者。暂不支持自动更新、OCR 或 ARM64；第三方应用的取词兼容性各不相同。

This is an unsigned preview; Windows may show an unknown publisher warning. Automatic updates, OCR and ARM64 are not supported yet. Text selection support varies across applications.
