# Glint 0.5.0 · Preview / 预览版

按应用表现选择合适的取词方式，让 PDF 取词和多屏使用更可靠。

Choose the capture method that works for your apps, with improved PDF capture and multi-monitor placement.

## 本次更新 / What's new

- **三种取词方式**：在「触发」页选择「辅助接口」「复制取词」或「按需复制」。复制取词直接复制选区并恢复剪贴板；按需复制仅在辅助接口取不到文字时尝试复制。/ Choose accessibility capture, direct copy, or copy on demand in Triggers. Direct copy restores the clipboard afterward; on-demand copy runs only when accessibility finds no text.
- **Zotero PDF 兼容**：辅助接口返回错误原文时，可切换到「复制取词」。本次已在用户的 Zotero PDF 场景中确认原文和翻译正常。/ Switch to direct copy if accessibility returns incorrect source text. Correct capture and translation were confirmed in the reported Zotero PDF case.
- **减少剪贴板历史干扰**：恢复旧内容时不再新增 Windows 历史条目，并尝试清理能够确认属于本次取词的临时记录；遇到并发复制或不明确的记录时跳过。/ Restored content is excluded from Windows clipboard history. Glint attempts to remove an identifiable temporary capture entry and skips cleanup when another copy or ambiguous records are detected.
- **多屏定位修复**：结果卡片跟随选区所在屏幕，已有卡片复用时也会重新定位。/ New and reused result cards follow the selection's display.
- **减少旧选区误用**：动作执行前核对选区，切换取词方式时清理旧选区；诊断日志补充取词方式、来源进程、字符数和请求阶段，不记录正文或密钥。/ Validate selections before running actions and discard old selections when changing capture modes. Diagnostics include capture method, source process, text length and request stages without logging text or credentials.

## 更新与数据 / Updating and data

更新前请从托盘菜单完全退出 Glint。旧版关闭复制取词时，升级后使用「辅助接口」；旧版开启时，升级后使用「按需复制」。已有设置、动作和记录继续保留。

Quit Glint from the tray menu before updating. The old disabled clipboard preference becomes accessibility capture; an enabled preference becomes copy on demand. Existing settings, actions and records are preserved.

记录保存在 `%LOCALAPPDATA%\Glint\data`，设置保存在 `%APPDATA%\Glint`。Portable 和安装版共用这些目录。

Records remain in `%LOCALAPPDATA%\Glint\data`, and settings in `%APPDATA%\Glint`. Portable and installed editions share these locations.

三种取词方式都遵循应用排除名单。「按需复制」无法识别辅助接口返回的错误文字，此时请使用「复制取词」。取词支持仍因应用而异；不支持 OCR。当前为未签名预览版，暂不提供自动更新或 ARM64 版本。

All capture modes respect app exclusions. Copy on demand cannot detect incorrect text returned by accessibility; use direct copy in that case. Capture support still varies by app, and OCR is not supported. This is an unsigned preview without automatic updates or ARM64 builds.

历史清理仅针对 Windows 的 Win+V，不保证临时记录从未出现，也无法还原因历史容量上限而被挤掉的条目；第三方剪贴板管理器不在此清理范围内。

History cleanup targets Windows Win+V only. Temporary entries may appear briefly, and entries evicted by Windows' history limit cannot be recovered. Third-party clipboard managers are not covered.
